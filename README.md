# 550C Boot · 流浪地球风格 Windows 开机动画

把电脑开机做成《流浪地球 2》里的 **550C 通用量子计算机**终端：UEG 人员登录 → 口令/人脸核验 → 550C 自检动画 → 进入桌面。

纯前端渲染，本地运行，不联网、不上传任何数据。

![登录界面](封面-登录界面.png)

![自检界面](封面-自检界面.png)

## 特性

- **UEG 授权终端登录页** — 深红/近黑配色、切角面板、扫描线、暗角、人员编号与权限等级
- **可自定义身份** — 人员编号（默认 `CY0`）、所属单位（默认「第一区 · 550 系列研发组」）、服役编号、驻地
- **6 位口令验证** — 装的时候自己设，错误会抖动提示
- **550C 自检动画** — 量子芯片阵列、超导环温度、冷聚变电池、行星发动机网络逐行滚动，12 秒
- **全屏 kiosk 播放** — 登录后自动触发，播放时自动隐藏桌宠等置顶窗口，播完恢复
- **一键安装 / 一键卸载**

## 安装

要求：Windows 10/11 + [Node.js](https://nodejs.org)（LTS 即可）

```
1. 解压
2. 双击 安装.bat
3. 输入你要用的 6 位数字口令（自己定，别用常用密码）
```

下次登录 Windows 就会看到。

卸载：双击 `卸载.bat`。

## 自定义

用记事本打开 `550c.html`，改动这几处：

| 位置 | 字段 |
|---|---|
| `人员编号 / STAFF ID` | `CY0` |
| `所属单位 / DIVISION` | `第一区 · 550 系列研发组` |
| `服役编号 / SERVICE NO.` | `UEG-1D-7749` |
| `驻地 / STATION` | `第一区 地下城 · 领航员空间站` |
| `const PASS = "000000"` | 口令 |

## 原理

- `550c.html` — 整个界面（CSS 动画 + Canvas 无关，纯 DOM），无外部依赖
- `play-boot.cjs` — 用 Edge 的 `--kiosk` 全屏打开，N 秒后关闭对应进程
- `pet-vis.ps1` — 播放前后调用 `ShowWindow` 隐藏/恢复桌宠等置顶窗口

## 已知限制

- Windows 真正的登录界面（LogonUI）无法替换，本项目的动画在**登录之后**播放
- 固件开机 logo（联想/戴尔等）属于 UEFI，不修改
